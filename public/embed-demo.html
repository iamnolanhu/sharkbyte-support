A pretend customer site

This page exists to show the SharkByte widget on a plain third-party page. It has no code of its own beyond the one script tag below, so the chat bubble in the corner is loaded cross-origin from the SharkByte site, the same way a customer's site would embed it.

The embed code

<script
  src="https://sharkbyte-support.vercel.app/widget.js"
  data-agent-id="029b5749-0b04-11f1-b074-4e013e2ddde4"
  data-primary-color="#0080FF"
  data-position="bottom-right"
  async
></script>
